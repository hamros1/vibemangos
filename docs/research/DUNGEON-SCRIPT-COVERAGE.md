# Vanilla dungeon and raid script coverage

Target version is World of Warcraft 1.12.1. The November 2026 audit compared the Classic-DB instance, spawn, AI, gossip, waypoint and loot tables with the D script registry and the real-data tests.

The world database has 26 dungeon and raid maps. Twenty-four have instance-wide D scripts. The Stockade and Ragefire Chasm use database creature AI for their named encounters, including Hamhock’s Chain Lightning and Bloodlust and Taragaman’s Fire Nova and Uppercut. The real-data tests now exercise both maps. [Contemporary Stockade run guide](https://www.wow-pro.com/22-30-james-the-stockade-instance-guide/)

| Instance | Gap and implementation | Evidence |
|---|---|---|
| Dire Maul North | Mizzle follows his database waypoints, crowns players through gossip, and produces the tribute chest on request. The Classic-DB loot rules use the number of surviving tribute bosses. The same instance cannot award another chest after the first has been looted. | [Blizzard’s Classic release announcement](https://worldofwarcraft.blizzard.com/en-us/news/23185723/wow-classic-dire-maul-now-available), [reference loot conditions](https://github.com/cmangos/mangos-classic/blob/master/src/game/AI/ScriptDevAI/scripts/kalimdor/dire_maul/instance_dire_maul.cpp#L499-L519) |
| Blackwing Lair | Suppression Devices pulse every five seconds. Disarm Trap disables an individual device for 30–120 seconds. The devices stop pulsing when Broodlord Lashlayer dies. The pulse timing and rearm range follow CMaNGOS’s packet-based implementation, and the aura radius and duration come from the spell data. | [2006 Blackwing Lair raid guide](https://www.tentonhammer.com/guides/blackwing-lair-guide-7-25-06-page-four), [reference device AI](https://github.com/cmangos/mangos-classic/blob/master/src/game/AI/ScriptDevAI/scripts/eastern_kingdoms/blackwing_lair/blackwing_lair.cpp#L732-L779) |
| Uldaman | A wipe at the first altar restores all four Stone Keepers. Archaedas targets the nearest eligible petrified dwarf when summoning an add. The four named statue templates already cast their combat spells and restore Stoned through database AI. | [2006 Uldaman run guide](https://www.wow-pro.com/35-45-james-uldaman-instance-guide/), [reference reset and dwarf selection](https://github.com/cmangos/mangos-classic/blob/master/src/game/AI/ScriptDevAI/scripts/eastern_kingdoms/uldaman/instance_uldaman.cpp#L208-L251) |

The audit establishes script coverage and checks the behavior above. Gluth’s exact Decimate trigger remains unresolved. Blizzard ruled out a fixed timer, and the emulator still uses an interval until original or Classic Era combat evidence establishes the trigger.
