Each entry represents one class and learned spell ID. Shared abilities appear once per class. The cast column records the generic real-data check. A pass can coexist with a gameplay defect from a targeted test. Passive entries were excluded by the cast sweep. The Hunter retest checked that each rank applied its aura when cast by a Hunter.

The last column compares the English 1.12.1 description rendered from local game data with the description on Wowhead Classic. **Match** allows punctuation, spacing and unit abbreviations. **Base/formula** also reconciles the online level-scaled amount to its base value or evaluates a numeric expression. **Different** means the rendered texts still differ. **Seasonal** means the online description includes a Season of Discovery alternative. **No text** means one or both descriptions were empty. **No record** means the online lookup returned no usable spell record.
